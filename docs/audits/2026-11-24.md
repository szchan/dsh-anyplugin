  absent and the workflow adds a second, false `verify skipped at least one
  test` error. Run `45383959106` shows this after the real `check:pack`
  failure, and run `45376277941` shows it after the install-smoke failure.
  Opened as #292; the fix belongs in a separate CI change, not this report-only
  PR.

  gate, not this report-only PR.
